# Cafe 104 — cafe104duluth.com

A website built for **Cafe 104**, a Korean-fusion brunch cafe located in Duluth, GA.

This was a commissioned project. Design direction, page structure, and features were planned and refined through ongoing discussion with the client.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- Deployed on [Vercel](https://vercel.com)
- Vercel Analytics & Speed Insights

## Pages

- **Home** — Hero, about section, photo gallery
- **Menu** — Tabbed menu by category (Seasonal, Drinks, Brunch, Dessert)
- **Gallery** — Full photo grid

## Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
